# 3D 지구 모델링
WebGL을 이용한 3D 지구 모델링 프로젝트입니다.

# 사용 방법
프로젝트 다운로드 후 로컬 웹 서버 환경에서 실행하실 수 있습니다.
(이미지 텍스처를 불러오는 과정에서 브라우저의 보안 정책 이슈 방지)

# 주요 기능
- 지구 표면 텍스처 매핑 (Texture Mapping)
- 고도 맵을 이용한 범프 매핑 (Bump Mapping)
- 좌회전, 우회전 및 정지
- 광원 슬라이더
- 마우스 휠을 이용한 확대 및 축소
- 화면 중앙의 위도 및 경도 표시 (Y축 기준으로 좌우 회전 구현, 사실상 중앙 위도는 0°)
